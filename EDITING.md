# Редактирование вики «МакГраты»

Рабочие тексты находятся в `content/`. Это единая версия материалов, из которой собирается публичный сайт https://jemimma-lor.github.io/mcgrath-wiki/.

## В браузере GitHub

Открой нужный `.md` в `content/`, нажми карандаш, измени текст и сохрани через Commit changes в ветку `main`. После успешного задания Publish McGrath wiki сайт обновится. История правок сохраняется в GitHub.

Ссылка на другую страницу: `[[Персонажи/Дороти МакГрат|Дороти]]`. В таблицах разделитель подписи нужно экранировать: `[[Персонажи/Дороти МакГрат\|Дороти]]`. Изображение: `![[images/имя-файла.jpg]]`; сам файл также загружается в указанную папку.

Не меняй имена файлов без обновления ссылок. Заголовок страницы можно изменить в поле `title` в начале файла, сохранив имя файла и адрес.

## Статусы

Разделяй произошедшее, утверждённые планы, предположения героев, авторские вопросы и архивные варианты. Приоритет: слово автора → посты → древо → заметки. Публикация обсуждения не превращает его в канон.

## Локальная сборка

Node.js 24. Установка: `npm ci`. Сборка: `npx quartz build`. Результат в `public/` создаётся заново при каждой сборке; править его вручную не следует.

Дизайн: `quartz/styles/custom.scss`. Настройки: `quartz.config.yaml`. Публикация: `.github/workflows/publish.yml`.

Вики была перенесена из локальной папки МакГраты. Изменения в GitHub не синхронизируются автоматически с этой исходной папкой или Notion. Не запускай первоначальный перенос повторно поверх новых правок.

Код Quartz распространяется на условиях его MIT-лицензии. Авторские тексты и иллюстрации не получают автоматически лицензию движка.
